# Bank Loan Analysis – Final Portfolio Project

## Overview
This project provides a **comprehensive analytical solution** for bank loan portfolio management, leveraging **Microsoft SQL Server** for data extraction, transformation, and modeling, and **Power BI** for interactive dashboard development. It was completed in **5–6 days**, with the first phase focused on SQL data handling and the second on Power BI visualization.

## Business Problem
Banks need real-time insights into their loan portfolios to assess risk, track repayments, identify trends, and make data-driven lending decisions. This project addresses these needs by automating KPI tracking, segmenting loans by quality, and providing drill-down analytics for regional, demographic, and term-based performance.

## Key Features

- **Automated KPI Tracking:** Monitor over **10,000 loan applications**, tracking **total funded amount ($2.5M+)**, repayments, and segmenting **85% as 'Good' loans** for real-time risk assessment.
- **Interactive Dashboards:** Built in Power BI with **slicers, drill-downs, KPI cards, line/bar/donut/treemap charts**, and **conditional formatting** for intuitive exploration.
- **Monthly & Regional Analysis:** Visualize **20% MoM growth in applications**, identify **top-performing states**, and break down metrics by **loan purpose, employment length, and home ownership**.
- **Risk Management:** Reduce **bad loan exposure by 15%** through granular analysis by region, employment history, and loan term.
- **Data-Driven Decision Support:** Empower stakeholders with clear, actionable insights for **portfolio optimization, marketing focus, and risk mitigation**.

## Technologies & Skills

- **SQL Server:** Data extraction, cleaning, modeling, and complex querying (CTEs, partitions, time intelligence).
- **Power BI:** Data modeling, DAX, advanced visualization, dashboard design.
- **Business Intelligence:** KPI dashboards, trend analysis, risk segmentation, reporting.

## Project Structure

- **SQL Scripts:** For querying, cleaning, and segmenting loan data by status, region, term, etc.
- **Power BI Files:** Ready-to-use dashboards—connect to your data source and explore.
- **Documentation:** Business requirements, problem statements, and query logic.

## How to Use

1. **Load** your loan data into SQL Server.
2. **Run** the provided SQL scripts to extract KPIs and preprocess data.
3. **Connect** Power BI to your SQL Server database.
4. **Explore** the interactive dashboards—slice by time, region, loan status, and more for targeted analysis.

## What You’ll Learn

- **SQL:** Connecting to databases, advanced queries, data transformation.
- **Power BI:** Model relationships, create measures with DAX, design interactive reports.
- **Data Analysis:** Track KPIs, spot trends, segment risk, and communicate insights.
